# TaskMate - To-Do List Application

A simple web application made with HTML, CSS and JavaScript for Software Engineering Assignment 01.

Features: add tasks, complete tasks, delete tasks, filter tasks, clear completed/all tasks, and localStorage persistence.

## Local test
Open `index.html` in a browser. For the automated check, install Node.js and run `npm test`.

## DevOps flow
Develop -> Test locally -> Commit -> Push -> GitHub Actions CI -> Fix errors if needed -> Deploy with GitHub Pages -> Verify live app.
