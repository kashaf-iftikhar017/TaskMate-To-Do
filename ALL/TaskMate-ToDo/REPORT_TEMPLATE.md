# Software Engineering Assignment 01
## Build and Deploy a Small Application

**Application:** TaskMate - To-Do List Application  
**Technology:** HTML, CSS, JavaScript  
**GitHub Repository:** [Paste link]  
**Live Application:** [Paste link]

### 1. Application Name and Purpose
TaskMate is a simple web-based to-do list application for organizing daily tasks. Users can add, complete, delete and filter tasks.

### 2. Main Features
- Add new tasks
- Mark tasks complete
- Delete tasks
- Filter All / Active / Completed
- Clear completed tasks
- Clear all tasks
- Save tasks using browser localStorage

### 3. DevOps Flow Followed
1. Created the application using HTML, CSS and JavaScript.
2. Tested it locally in a browser.
3. Created a GitHub repository.
4. Uploaded the source code.
5. Made at least three meaningful commits.
6. Created GitHub Actions CI workflow.
7. Configured CI to run automatically on pushes to main.
8. Added automated build/test checks.
9. Introduced a small error, captured the failed CI run, fixed it, and captured the successful run.
10. Deployed the application using GitHub Pages.

### 4. Problems Faced and How They Were Solved
A CI check failed after a small code mistake was intentionally introduced. I read the GitHub Actions error log, corrected the code, committed the fix and pushed it again. The workflow then completed successfully.

### 5. What I Learned from Continuous Integration (CI)
I learned that CI automatically checks code after changes are pushed. It helps detect errors early and gives developers quick feedback before code is deployed.
